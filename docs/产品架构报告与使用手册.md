# 素材工具包 (Media & Web Intelligence Toolkit) · 产品架构报告与使用手册

> **定位**：面向内容创作者、行业研究员与开发者的**全本机音视频采集、网页正文提取、语音转写与 AI 归纳工作台**。  
> **核心链路**：`Download（多平台音视频）` → `Scrape（反爬网页抓取）` → `Transcribe（原生字幕秒提 / Whisper 本地转写）` → `Summarize（DeepSeek 单条总结与跨视频横向对比）`。

---

## 1. 产品设计哲学与核心优势

| 维度 | 传统零散脚本方案 | 本工具包 (v2.0 Unslop 整合版) |
|---|---|---|
| **交互体验** | 20+ 个分散的 `.bat` 批处理窗口，黑框闪烁、参数靠手敲 | **三栏式工业深色工作台**（遵循 `heydamir/unslop` Graphite Dark 规范），左侧导航、中央参数卡片 + 实时终端、右侧富文本排版检视器 |
| **登录态管理** | 手动导出静态 `cookies.txt`，几分钟后令牌轮换即报 `HTTP 403` | **全链路直读 Firefox 实时 SQLite 库**（YouTube / B站 / 抖音 / 小红书通用），运行时自动复制临时库规避文件锁，一次登录长期有效 |
| **视频转写效率** | 无论有无字幕一律跑 CPU Whisper，10 分钟视频苦等 5~6 分钟 | **原生字幕秒级快速通道**：优先通过 `yt-dlp` 秒抓平台人工/AI 字幕并解析为标准时间轴，无字幕才平滑切入本地 Whisper 模型 |
| **批量调研能力** | 仅输出单条文字稿与简单词频，需人工逐篇阅读对比 | **AI 跨视频横向对比引擎**：批量采集转写后自动调用大模型，在 `汇总.md` 顶部生成「核心共识 + 差异对比 + 落地结论」报告 |
| **小红书与抖音** | `yt-dlp` 抖音提取器因缺 `a_bogus` 签名失效，小红书遇视频笔记报错中断 | **自研无水印解析引擎**：抖音走分享页 `_ROUTER_DATA` 直提无水印流；小红书自动识别「图集原图」与「视频笔记 MP4」双模式分流 |
| **环境与代码解耦** | 虚拟环境与业务代码混放，动辄数 GB 无法上传 GitHub | **代码与重型运行时彻底分离**：仓库源码仅数百 KB，外部依赖统一安装在 `%LOCALAPPDATA%\Programs\` 与两个隔离 Python `venv` 中 |

├─ 启动素材工具箱.bat               # [备用入口] exe 双击没反应时用，自动探测本机 whisper / scrapling 虚拟环境
├─ 一键安装环境依赖.bat             # [环境安装] 双击安装缺失的 9 项依赖（完整模式）
├─ 一键安装环境依赖.ps1             # [环境安装] 安装脚本本体（-Mode Quick 只装下载链；缺什么装什么，已有的不动）

├─ docs/
│   └─ 产品架构报告与使用手册.md      # [完整报告] 架构设计、数据契约、自检审计与二次开发手册（本文档）
├─ download/                       # [子系统 ①] 多站点音视频下载 (yt-dlp + 抖音无水印)
│   ├─ douyin.js                   # 抖音分享页无水印下载脚本（已升级支持直读 Firefox 实时 Cookie）

│   ├─ llm_config.sample.txt       # 大模型配置模板（复制为 llm_config.txt 填入 KEY/BASE/MODEL）
│   ├─ README.md                   # Whisper 模型对比与实测性能基准
│   └─ 批量分析-平台能力.md          # 各平台搜索接口限制与风控退避机制说明

│   ├─ 示例-抓取与解析.py            # HTTP TLS 指纹伪装 / Patchright 浏览器渲染 / Cloudflare 穿透示例
│   ├─ YouTube搜索抓取.py           # 免登录抓取 YouTube 搜索结果并导出 UTF-8-BOM CSV 表格
│   └─ README.md                   # Scrapling 与 yt-dlp 互补协作指南

│   └─ xhs.bat                     # 拖拽式快捷批处理入口

## 3. 运行时依赖矩阵（外部隔离安装）

所有体积庞大的二进制程序与深度学习依赖均安装在 `%LOCALAPPDATA%\Programs\` 下，不污染代码仓库。工作台的 **「环境与依赖 (快捷键 6)」** 面板提供一键实时核验：

| 序号 | 组件名称 | 推荐版本 | 默认安装路径 | 职责与服务模块 |
|---|---|---|---|---|
| 1 | **yt-dlp** | `2026.10.26+` | `%LOCALAPPDATA%\Programs\yt-dlp\yt-dlp.exe` | `download` / `summarize` 音视频与原生字幕拉取 |
| 2 | **ffmpeg / ffprobe** | `9.0.2+` | `%LOCALAPPDATA%\Programs\ffmpeg\bin` | 音视频轨道合并、16kHz 单声道 WAV 重采样 |
| 3 | **deno** | `2.9.8+` | `%LOCALAPPDATA%\Programs\deno` | YouTube `nsig` / JS 挑战快速求解 |
| 4 | **bgutil POT Provider** | `2.0.2+` | `%USERPROFILE%\bgutil-ytdlp-pot-provider` | YouTube 高清流 PO Token 本地签发 (`127.0.0.1:4416`) |
| 5 | **Whisper Venv (Py 3.12)** | `whisper 20250625` | `%LOCALAPPDATA%\Programs\whisper\venv` | 本地离线语音识别（搭配 `opencc` 自动繁转简） |
| 6 | **Scrapling Venv (Py 3.14)** | `scrapling 0.5.1` | `%LOCALAPPDATA%\Programs\scrapling\venv` | `curl_cffi` TLS 指纹伪装与网页 Markdown 提取 |
| 7 | **Playwright Browsers** | `chromium 1248/1255` | `%LOCALAPPDATA%\ms-playwright` | 动态 JS 页面渲染与 Cloudflare Turnstile 盾穿透 |
| 8 | **Node.js** | `24.15.0+` | `C:\Program Files\nodejs\node.exe` | 执行 `douyin.js` / `xhs.js` 并提供内置 `node:sqlite` |
| 9 | **Mozilla Firefox** | `160+` | `C:\Program Files\Mozilla Firefox\firefox.exe` | 提供全链路免导出实时登录态 (`cookies.sqlite`) |

## 4. 四大子系统功能与数据契约

### 4.1 下载中心 (`download`)
- **支持模式**：`1080p 视频 (H264+封面)`、`视频 + 中英字幕 + 封面`、`提取 MP3 音频`、`抖音无水印专下`、`播放列表/频道追更`、`YouTube 关键词搜索批量下载`、`列出格式 (-F)`。
- **编码净化**：自动注入 `--encoding utf-8`，配合主程序 `UTF-8 / GB18030` 双编码自适应管道，彻底解决中文 Windows 下控制台路径乱码。
- **去重机制**：YouTube 批量下载使用 `download/downloaded-youtube.txt` 记录已完成 ID；播放列表使用输出目录下的 `archive.txt`，支持断点续传。

### 4.2 转写与总结 (`summarize`)
- **单条处理 (`pipeline.py`)**：
  1. **原生字幕秒提**：先探测目标视频是否有平台自带字幕（人工或自动字幕），若有则 1~2 秒内直接转存为标准时间轴，跳过耗时数分钟的音频下载与 Whisper 识别（可通过 `--force-asr` 强制使用 Whisper）。
  2. **Whisper 本地转写**：无原生字幕时自动提取 16kHz 单声道 WAV 并调用本机 Whisper 模型识别，中文自动经 `opencc` 转换为简体中文与标准标点。
  3. **双引擎摘要**：支持 `AI 结构化总结`（读取 `llm_config.txt` 调用 DeepSeek/OpenAI）与 `本地 TF-IDF 规则摘要`（无 Key 时自动无缝回退）。
- **批量平台分析 (`batch_platform.py`)**：
  - 支持 **B站关键词全自动搜索 (`bilisearch`)** 与 **抖音/小红书链接列表**。
  - 全部条目转写完成后，自动调用大模型生成 **《AI 跨视频横向对比与综合结论》**，写入 `汇总.md` 顶部。

### 4.3 网页抓取 (`scrape`)
- **三级抓取模式**：
  - `模式 1 (http)`：基于 `curl_cffi` 伪装 Chrome TLS 指纹，1~2 秒极速提取正文并转为干净 Markdown。
  - `模式 2 (browser)`：启动无头浏览器等待 `--network-idle`，完整获取 SPA 动态渲染内容。
  - `模式 3 (cloudflare)`：启用 `--solve-cloudflare` 自动过 Turnstile 盾。
- **YouTube 搜索结果导出 CSV**：免登录直接解析 `ytInitialData`，2 秒内导出包含 `video_id, title, length, channel, views` 的 UTF-8-BOM CSV 表格。

### 4.4 小红书图文与视频 (`xhs`)
- **登录态**：优先通过 `node:sqlite` 读取 Firefox 实时登录态（自动拷贝临时库避免锁冲突）。
- **图文 + 视频自动分流**：解析页面内嵌 `__INITIAL_STATE__`，图文笔记下载全部无水印原图 (`01.jpg ... NN.jpg`)；视频笔记自动提取 H264/H265 主流下载 `video.mp4` + `cover.jpg`；同时生成包含标题、作者、点赞收藏数、话题标签与正文的 `笔记.txt`。

## 5. 右侧产出检视器 (Rich Inspector) 使用说明

工作台右侧栏专为“即跑即看、即看即用”设计：
1. **排版视图 / 源码视图一键切换**：
   - `.md` 文件自动渲染为带琥珀色章节标尺、元数据引用块、高亮时间戳徽章（`00:01:23`）与要点列表的排版视图；
   - `.srt` 字幕文件自动合成为双栏「时间码 + 台词」时间轴视图；
   - `.csv` 搜索结果自动渲染为带固定表头的结构化数据表格；
   - 小红书 `笔记.txt` 自动提取顶部「标题 / 作者 / 类型 / 互动量 / 话题」信息卡片。
2. **定位目录 (`explorer /select`)**：点击检视器工具栏上的 **「定位目录」**，系统会直接打开 Windows 资源管理器并**高亮选中当前正在预览的那个文件**，方便你直接拖拽分享或二次编辑。
3. **打开文件 / 复制全文**：一键调用系统默认编辑器打开该文件，或将全文复制到剪贴板。

## 6. 命令行 (CLI) 自动化接口

除图形界面外，`素材工具箱.exe`（或 `python toolkit_app.py`）支持完整的命令行参数，方便写入定时任务或被其他 Agent 调用：

```powershell
# 1. 检查全部 9 项外部运行时依赖
.\素材工具箱.exe check

# 2. 下载视频 / 音频 / 抖音无水印
.\素材工具箱.exe download "https://www.youtube.com/watch?v=xxxx" --mode 1080p
.\素材工具箱.exe download "https://v.douyin.com/xxxx/" --mode douyin

# 3. 单条视频转写 + AI 总结（优先秒提自带字幕，加 --force-asr 强制跑 Whisper）
.\素材工具箱.exe summarize "https://www.bilibili.com/video/BVxxxx" --mode ai --model small --lang zh

# 4. B站关键词批量下载 + 转写 + AI 跨视频横向对比汇总
.\素材工具箱.exe batch "Python 教程" --mode bilibili --count 3 --model small

# 5. 网页抓取转 Markdown / YouTube 搜索结果导出 CSV
.\素材工具箱.exe scrape "https://example.com" --mode http
.\素材工具箱.exe scrape "lofi hip hop" --mode yt_csv

# 6. 小红书图文/视频无水印下载
.\素材工具箱.exe xhs "https://www.xiaohongshu.com/explore/xxxx?xsec_token=..."
```

## 7. GitHub 开源发布前深度自检与改进建议

在对原压缩包进行全量代码审计时，我发现了几个**上传 GitHub 前必须注意的工程与安全事项**，并已在本次打包中为你做好了防护工具：

### 7.1 已为你内置的 GitHub 安全防护
1. **高危提醒：原包内含有明文 API Key 与个人登录 Cookie**
   - 原 `summarize/llm_config.txt` 中包含明文 DeepSeek Key（`sk-xxx`，已脱敏）；
   - 原 `download/cookies.txt` 与 `download/cookies-src/*.txt` 中包含 B站、抖音、YouTube、小红书的完整登录态 Cookie（共 1.1 万余行）。
   - **已做处理**：
     - 我已在根目录自动生成了严格的 **`.gitignore`**，默认将 `llm_config.txt`、`cookies.txt`、`cookies-src/`、`OUT.txt` 及产出目录全部加入 Git 忽略名单；
     - 公开包本身已脱敏：`llm_config.txt`、`cookies.txt`、`cookies-src/` 等敏感文件已从发布包中移除，只留 `llm_config.sample.txt` 和 `config.sample` 供其他用户参考；`.gitignore` 已默认拦截 `llm_config.txt` 与 `cookies.txt`，避免误提交。
2. **动态路径适配（消除硬编码用户名）**
   - 原本的说明与部分配置写死了 `C:\Users\<你的用户名>\` 和 `%USERPROFILE%\Videos\yt-dlp`。现在主程序全面采用 `%LOCALAPPDATA%`、`%APPDATA%` 与 `%USERPROFILE%` 环境变量动态解析；其他用户克隆你的 GitHub 仓库后，只需双击根目录唯一的 `素材工具箱.exe`（通用启动器，在 PATH 里找 `python.exe`，不绑定任何一台电脑），或双击 `启动素材工具箱.bat` 自动探测本机虚拟环境。

### 7.2 后续版本（v2.1+）可继续演进的方向
- **一键环境初始化脚本**：已实现——根目录 `一键安装环境依赖.ps1`（双击入口 `一键安装环境依赖.bat`，工作台「环境与依赖」页也有「快速安装缺失依赖（下载链）」「完整安装缺失依赖（全部 9 项）」两个按钮）。逐项对照 `inspect_all_dependencies()` 的 9 项检查、缺什么装什么，已有的不动；Quick 只装下载链（yt-dlp / ffmpeg / deno / Node.js / Firefox），Full 再补 POT、Whisper / Scrapling 虚拟环境与浏览器内核；POT 一步为尽力而为，失败只警告，不影响其余项。
- **支持 `faster-whisper` GPU / CPU INT8 加速切换**：当处理无自带字幕的 1 小时以上长视频时，引入 `faster-whisper` 可将 CPU 转写耗时再缩短 65% 以上。
